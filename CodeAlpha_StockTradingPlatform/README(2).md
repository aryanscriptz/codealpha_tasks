# Stock Trading Platform

A Java console-based application that simulates basic stock trading. Users can view available stocks, buy and sell shares, manage their portfolio, and check their transaction history.

## Features

- View available stocks and prices
- Buy stocks
- Sell owned stocks
- Track available cash balance
- View current portfolio
- View transaction history
- Check total portfolio value
- Prevent purchases when balance is insufficient
- Prevent selling more shares than owned

## Technologies Used

- Java
- HashMap
- ArrayList
- Scanner
- Object-Oriented Programming

## Project Structure

```
StockTradingPlatform/
└── StockTradingPlatform.java
```

## How to Run

Compile the program:

```
javac StockTradingPlatform.java
```

Run the program:

```
java StockTradingPlatform
```
