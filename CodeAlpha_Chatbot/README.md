# ARONE - Java Desktop AI Chatbot

ARONE is a desktop-based AI chatbot developed in Java using Swing. It
provides an interactive conversational interface capable of answering
programming, technology, science, and general knowledge queries through
a rule-based Natural Language Processing (NLP) engine.

Designed with a modern neon-themed user interface, ARONE demonstrates
the practical implementation of Java GUI development, object-oriented
programming, data structures, and pattern matching techniques without
relying on external APIs or machine learning frameworks.

------------------------------------------------------------------------

## Overview

ARONE is built to showcase the fundamentals of chatbot development using
core Java. It processes user input through keyword recognition and
intelligently selects the most relevant response from its knowledge
base.

### Features

-   Modern dark-themed graphical user interface
-   Interactive real-time chat experience
-   Rule-based NLP engine
-   Regex-based keyword matching
-   Extensive built-in knowledge base
-   Runtime user name recognition
-   Offline functionality (No Internet Required)

## Technologies Used

-   Java
-   Java Swing
-   AWT
-   HashMap
-   Regular Expressions
-   Object-Oriented Programming

## Working Principle

1.  User enters a message.
2.  Input is normalized.
3.  Keywords are matched using Regular Expressions.
4.  The knowledge base is searched.
5.  The best matching response is returned.
